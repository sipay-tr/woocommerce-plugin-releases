# Sipay WooCommerce Plugin — Releases

This repository hosts the official downloadable releases of the **Sipay WooCommerce payment plugin**. Download a ready-to-install `.zip` package from the Releases page below.

## Download the latest release

1. Open the [**Releases**](https://github.com/sipay-tr/woocommerce-plugin-releases/releases/latest) page.
2. Download the **`sipay-woocommerce-plugin-<version>.zip`** file under the latest release.

## Installation

1. In the WordPress admin, go to **Plugins → Add New → Upload Plugin**.
2. Choose the downloaded `.zip` file and click **Install Now**.
3. Once installed, click **Activate Plugin**.
4. Go to **WooCommerce → Settings → Payments** to enable Sipay and enter your API credentials.

> To update, repeat the same steps with the newest `.zip`; WordPress installs it over the existing plugin.

## Requirements

- A WordPress site with WooCommerce installed and active.
- A valid Sipay merchant account and API credentials.
